# 29 — Match any character

Implement `char *my_strpbrk(const char *s, const char *accepted)`.

Return the first character in `s` belonging to `accepted`, or `NULL` if none.
Inputs are valid strings and remain unchanged. Their terminating null bytes
are not characters to match. No library set-search functions; earlier helpers
are allowed.

Example: `("hello,world", ",;")` → input + 5.

There are additional edge cases to consider.

Run `make run N=29`; check with `make test N=29`.
