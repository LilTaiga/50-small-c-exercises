# 29 — Match any character

Implement `char *my_strpbrk(const char *s, const char *accepted)`.

Given two strings `s` and `accepted`, search `s` for the first character that
appears in `accepted` and return a pointer to it. Return `NULL` if none of the
characters of `s` appear in `accepted`.

Examples:

- s `"hello,world"`, accepted `",;"` -> `s + 5`
- s `"name=value"`, accepted `"=:"` -> `s + 4`
- s `"123abc"`, accepted `"0123456789"` -> `s`
- s `"baba"`, accepted `"aab"` -> `s`
- s `"abc"`, accepted `"xyz"` -> `NULL`
- s `"abc"`, accepted `""` -> `NULL`
- s `""`, accepted `"abc"` -> `NULL`

> [!Tip]
> This is similar to [`my_strcspn`](./28.md), but it returns a pointer instead
> of a count.

Run `make run N=29`; check with `make test N=29`.
