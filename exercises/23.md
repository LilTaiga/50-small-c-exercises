# 23 — Move overlapping memory

Implement `void *my_memmove(void *destination, const void *source, size_t count)`.

Copy exactly `count` bytes as though the source were first saved elsewhere.
Return destination. Both pointers are valid and the regions have sufficient
readable/writable bytes; they may overlap or belong to separate objects.
Use constant extra space, with no allocation and no library memory-moving or
copying functions. Earlier helpers are allowed. Only destination bytes change.

Example: moving five bytes from `text` to `text + 1` in `"abcdef"` gives `"aabcde"`.

There are additional edge cases to consider.

Run `make run N=23`; check with `make test N=23`.
