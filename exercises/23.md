# 23 — Move overlapping memory

Implement `void *my_memmove(void *destination, const void *source, size_t count)`.

Given a `destination` pointer, a `source` pointer, and a number `count`, copy
the first `count` bytes of `source` into `destination` and return a pointer to
`destination`.
Unlike `my_memcpy`, `source` and `destination` may overlap. The result must be
the same as if `source` had first been copied somewhere else.
You are not allowed to allocate a new buffer.

Examples:

- destination `"XXX"`, source `"abc"`, count `3` -> `"abc"`
- destination `"dog"`, source `"cat"`, count `0` -> `"dog"`
- buffer `"abcdef"`, destination `buffer + 1`, source `buffer`, count `5` -> `"aabcde"`
- buffer `"abcdef"`, destination `buffer`, source `buffer + 1`, count `5` -> `"bcdeff"`
- buffer `"abcdef"`, destination `buffer`, source `buffer`, count `6` -> `"abcdef"`
- buffer `00 01 02 03 04 05`, destination `buffer + 2`, source `buffer`, count `4` -> `00 01 00 01 02 03`
- buffer `00 01 02 03 04 05`, destination `buffer`, source `buffer + 2`, count `4` -> `02 03 04 05 04 05`

Run `make run N=23`; check with `make test N=23`.
