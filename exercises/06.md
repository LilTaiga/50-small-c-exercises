# 06 — Lowercase

Implement `int my_tolower(int c)`.

Convert ASCII `A`–`Z` into `a`–`z`. Return all other inputs unchanged. Accept any
`int`. Do not use `<ctype.h>`. Earlier helpers are allowed.

Examples: `'G'` → `'g'`; `'!'` → `'!'`.

Boundary cases: `'A'` → `'a'`, `'Z'` → `'z'`; `'@'` and `'['` are unchanged.
Lowercase letters, `-1`, and `256` are unchanged too.

Run `make run N=6`; check with `make test N=6`.
