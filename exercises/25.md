# 25 — Search memory

Implement `void *my_memchr(const void *memory, int value, size_t count)`.

Search exactly `count` bytes for the first byte equal to `value` converted to
`unsigned char`. Return its address or `NULL`. Memory is valid and readable
for the requested count; preserve it. No library search functions; earlier
helpers are allowed.

Example: search `41 00 FF 41` for `0xFF` → buffer + 2.

There are additional edge cases to consider.

Run `make run N=25`; check with `make test N=25`.
