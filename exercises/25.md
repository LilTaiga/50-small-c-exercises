# 25 — Search memory

Implement `void *my_memchr(const void *memory, int value, size_t count)`.

Given a `memory` pointer, a `value`, and a number `count`, search the first
`count` bytes of `memory` for the first occurrence of `value` and return a
pointer to that byte. Return `NULL` if the value wasn't found.

Examples:

- memory `"banana"`, value `'n'`, count `6` -> `memory + 2`
- memory `"banana"`, value `'n'`, count `2` -> `NULL`
- memory `"banana"`, value `'b'`, count `0` -> `NULL`
- memory `41 00 FF 41 42`, value `0x41`, count `5` -> `memory`
- memory `41 00 FF 41 42`, value `0x00`, count `5` -> `memory + 1`
- memory `41 00 FF 41 42`, value `0x42`, count `5` -> `memory + 4`
- memory `41 00 FF 41 42`, value `0x42`, count `4` -> `NULL`
- memory `41 00 FF 41 42`, value `-1`, count `5` -> `memory + 2`
- memory `41 00 FF 41 42`, value `0x141`, count `5` -> `memory`

> [!Tip]
> Unlike [`my_strchr`](./14.md), `my_memchr` doesn't stop at a null byte; it
> always searches exactly `count` bytes.

> [!Important]
> As in [exercise 21](./21.md), only the lowest byte of `value` is used. So
> `-1` searches for `0xFF`, and `0x141` searches for `0x41`.

Run `make run N=25`; check with `make test N=25`.
