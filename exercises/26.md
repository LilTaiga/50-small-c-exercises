# 26 — Find a substring

Implement `char *my_strstr(const char *haystack, const char *needle)`.

Return the first substring match inside haystack, or `NULL`. An empty needle
matches at the start of haystack. Inputs are valid null-terminated strings and
remain unchanged. No library substring-search functions; earlier helpers are
allowed. A simple nested-loop algorithm is sufficient.

Examples: `("hello world", "world")` → haystack + 6;
`("banana", "ana")` → haystack + 1.

There are additional edge cases to consider.

Run `make run N=26`; check with `make test N=26`.
