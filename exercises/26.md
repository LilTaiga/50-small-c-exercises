# 26 — Find a substring

Implement `char *my_strstr(const char *haystack, const char *needle)`.

Given two strings `haystack` and `needle`, search `haystack` for the first
occurrence of `needle` and return a pointer to where it starts. Return `NULL`
if `needle` wasn't found.

Examples:

- haystack `"hello world"`, needle `"world"` -> `haystack + 6`
- haystack `"banana"`, needle `"ana"` -> `haystack + 1`
- haystack `"aaaaab"`, needle `"aaab"` -> `haystack + 2`
- haystack `"abc"`, needle `"x"` -> `NULL`
- haystack `"abc"`, needle `"abcd"` -> `NULL`
- haystack `"abc"`, needle `""` -> `haystack`
- haystack `""`, needle `""` -> `haystack`

> [!Warning]
> An empty `needle` is found at the start of any `haystack`, even an empty one.

> [!Tip]
> A loop inside another loop is enough here; you don't need a clever algorithm.

Run `make run N=26`; check with `make test N=26`.
