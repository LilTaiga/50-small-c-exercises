# 20 — Reverse in place

Implement `void reverse_string(char *s)`.

Given a string `s`, reverse its characters.
You are not allowed to allocate a new buffer to copy the string into.

Examples:

- `"hello"` -> `"olleh"`
- `"abcd"` -> `"dcba"`.

> [!Tip]
> Maybe some of the functions you implemented earlier can be of help here?

Run `make run N=20`; check with `make test N=20`.
