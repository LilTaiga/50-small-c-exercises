# 20 — Reverse in place

Implement `void reverse_string(char *s)`.

Input is a writable null-terminated byte string. Reverse its non-null bytes in
place; leave the terminator at its original index and later bytes untouched.
Use constant extra space, without allocation or library reversal functions.
Earlier helpers are allowed. This operates on bytes, not Unicode characters.

Example: `"hello"` → `"olleh"`.

There are additional edge cases to consider.

Run `make run N=20`; check with `make test N=20`.
