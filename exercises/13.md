# 13 — Compare strings

Implement `int my_strcmp(const char *a, const char *b)`.

Given two valid null-terminated strings `a` and `b`, compare them in
**lexicographic order**.

Return:

- **A negative integer** if `a` comes before `b`.
- **Zero** if `a` and `b` are equal.
- **A positive integer** if `a` comes after `b`.

Examples:

- `("cat", "dog")` -> `negative`
- `("cat", "car")` -> `positive`
- `("cat", "cat")` -> `zero`
- `("cat", "cats")` -> `negative`
- `("", "cat")` -> `negative`

> [!Warning]
> While **lexicographic order** implies working only with letters,
> this function expects to work through the full range `0x00` to `0xFF`.
> When comparing, byte `0xFF` should sort higher than byte `0x7F`.

Run `make run N=13`; check with `make test N=13`.
