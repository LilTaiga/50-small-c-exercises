# 13 — Compare strings

Implement `int my_strcmp(const char *a, const char *b)`.

Inputs are valid null-terminated strings. Return a negative value, zero, or a
positive value when `a` sorts before, equal to, or after `b`. Compare bytes as
`unsigned char`. The exact nonzero magnitude is unspecified. Do not modify
inputs or call library comparison functions. Earlier helpers are allowed.

Examples: `("cat", "dog")` → negative; `("cat", "cat")` → zero.

Boundary cases: an empty string precedes a nonempty string; a prefix precedes
its longer string. Byte `0xFF` follows byte `0x7F`, even if plain `char` is signed.

Run `make run N=13`; check with `make test N=13`.
