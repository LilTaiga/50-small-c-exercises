# 19 — Bounded append

Implement `char *my_strncat(char *destination, const char *source, size_t count)`.

Append at most `count` non-null source bytes, then terminate the resulting
string. Return destination. Inputs are valid strings, do not overlap, and
destination has enough space for its original contents, the appended bytes,
and the terminator. Leave later bytes unchanged and preserve source.
`count` limits source bytes, not total destination capacity. No library
concatenation functions; earlier helpers are allowed.

Example: `"hello"`, `" C world"`, count `2` → `"hello C"`.

There are additional edge cases to consider.

Run `make run N=19`; check with `make test N=19`.
