# 19 — Bounded append

Implement `char *my_strncat(char *destination, const char *source, size_t count)`.

Given two strings `source` and `destination`, and a number `count`, append at
most `count` characters from the `source` into the `destination`, appending a
null byte at the end, and return a pointer to `destination`.
Assume that `destination` has enough capacity for the characters of `source` and the null byte.

Examples:

- `"hello"`, `" C world"`, count `2` -> `"hello C"`
- `"abc"`, `"defghi"`, count `3` -> `"abcdef"`

Run `make run N=19`; check with `make test N=19`.
