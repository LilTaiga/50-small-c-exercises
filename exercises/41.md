# 41 — Count set bits

Implement `unsigned bit_count(unsigned value)`.

Return the number of bits whose value is one in an `unsigned int`. Use the
actual width of the type, not an assumed 32 bits. No compiler population-count
builtins or library bit-count helpers. Earlier helpers are allowed.

Examples: `0xA5` (binary `10100101`) → `4`; `7` → `3`.

Run `make run N=41`; check with `make test N=41`.
