# 36 — Allocate zeroed memory

Implement `void *my_calloc(size_t count, size_t size)`.

Check that `count * size` is representable in `size_t`, allocate that many bytes,
and set every byte to zero. Return `NULL` for multiplication overflow, zero total
size, or allocation failure. This course's zero-size policy is intentionally
more specific than the standard library's. The caller frees successful results.

Use real `malloc`/`free` and your earlier memory-fill helper. Do not call real
`calloc` or library memory-fill functions. Returned storage must have malloc's
normal alignment.

Example: `(4, 2)` → eight zero bytes.

Run `make run N=36`; check with `make test N=36`.
