# 37 — Clone an integer array

Implement `int *array_clone(const int *values, size_t count)`.

Return a newly allocated independent copy of `count` integers. Return `NULL`
for zero count, size multiplication overflow, or allocation failure. Validate
the allocation size before reading input. For a nonzero representable size,
input provides `count` readable integers; otherwise it need not be readable.
Do not modify input. Caller owns and frees the result.

Use real `malloc`/`free` and earlier helpers; no library memory-copy functions.

Example: `[3, 1, 4]` → a separately allocated `[3, 1, 4]`.

Run `make run N=37`; check with `make test N=37`.
