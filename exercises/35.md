# 35 — Duplicate a string

Implement `char *my_strdup(const char *s)`.

Allocate enough memory for a complete independent copy including the null byte.
Return the writable copy, or `NULL` on allocation/size failure. Input is a valid
string and remains unchanged. The caller owns the result and releases it with
`free`. Use real `malloc`/`free`; do not call library string functions. Reuse
your earlier length/copy helpers.

Example: duplicating `"hello"` yields a separately owned `"hello"`.
Duplicating `"systems"` yields a separately owned `"systems"`.

Run `make run N=35`; check with `make test N=35`.
