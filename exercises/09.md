# 09 — Swap through pointers

Implement `void swap_int(int *a, int *b)`.

Both pointers address valid writable integers. Exchange their values. Use no
library swap helper; earlier helpers are allowed.

Example: integers `3` and `8` become `8` and `3`.

Boundary cases: equal values remain equal; both pointers may refer to the same
integer, which must stay unchanged. Any `int` value is valid, including limits.
Null pointers are outside the contract.

Run `make run N=9`; check with `make test N=9`.
