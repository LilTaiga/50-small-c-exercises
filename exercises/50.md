# 50 — Read an owned line

Implement `int read_line(FILE *stream, char **line, size_t *length)` using your
growable buffer from exercise 47, moved into `lib.c`.

Read through the next newline or EOF. On a line, return `1` and allocate its
contents without the newline, followed by a null byte. Write the content byte
count to `*length`; embedded null bytes are content and count toward length.
Preserve carriage returns. A newline itself constitutes a line; EOF before any
content does not. Return `0` for EOF without a line, `-1` for I/O, size, or
allocation failure. For either non-success result set `*line = NULL` and
`*length = 0`, releasing partial allocations.

All argument pointers are valid; stream is readable. Do not close or rewind it.
The caller frees each successful result before the next call. Use `fgetc`,
`ferror`, real allocation functions, and earlier helpers. Do not use `getline`,
`getdelim`, `fgets`, `scanf`, or library routines that read a whole line.

Example: stream containing `hello\nworld\n` → two successive owned lines.

Run `make run N=50`; check with `make test N=50`.
