# 43 — Encode little-endian bytes

Implement `void write_u32_le(unsigned char bytes[4], uint32_t value)`.

Write exactly four bytes, least significant byte first. Output provides four
writable bytes and may be unaligned for integer access. This exercise requires
8-bit bytes and `uint32_t`. Preserve surrounding memory. Use shifts and bitwise
operations, not integer-pointer casts or library endian-conversion functions.
Earlier helpers are allowed.

Examples: `0x12345678` → `78 56 34 12`; `0x89ABCDEF` → `EF CD AB 89`.

Run `make run N=43`; check with `make test N=43`.
