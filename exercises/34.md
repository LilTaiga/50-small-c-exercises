# 34 — Parse a selected base

Implement `ParseResult parse_uint_base(const char *s, unsigned base, unsigned *result)`.

Bases 2–36 are supported. Parse the whole nonempty string, using digits `0`–`9`
and case-insensitive ASCII `a`–`z` for values 10–35. No signs, whitespace, or
prefix notation. Return `PARSE_INVALID` for unsupported bases or invalid syntax;
`PARSE_OVERFLOW` for syntactically valid numbers greater than `UINT_MAX`; otherwise
write the value and return `PARSE_OK`. Leave output unchanged on failure.
Both pointers are valid; preserve input. Use `<limits.h>`.

No library number parsers. Earlier helpers are allowed.

Examples: `("FF", 16)` → `255`; `("1011", 2)` → `11`.

Run `make run N=34`; check with `make test N=34`.
