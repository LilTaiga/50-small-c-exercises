# 07 — Absolute value

Implement `int my_abs(int value)` without `abs`, `labs`, or `llabs`.
Earlier helpers are allowed.

Input is any `int` **except `INT_MIN`**. Return its nonnegative magnitude.
On ordinary two's-complement machines, `-INT_MIN` cannot fit in an `int`;
the standard `abs` does not define that result either. We do not test it.

Examples: `-42` → `42`; `12` → `12`.

Run `make run N=7`; check with `make test N=7`.
