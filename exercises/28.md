# 28 — Rejected prefix

Implement `size_t my_strcspn(const char *s, const char *rejected)`.

Return the length of the initial segment of `s` containing no character listed
in `rejected`. Both inputs are valid strings and remain unchanged. A string's
terminating null byte ends the scan. No library span functions; earlier helpers
are allowed.

Examples: `("hello,world", ",;")` → `5`; `("name=value", "=")` → `4`.

There are additional edge cases to consider.

Run `make run N=28`; check with `make test N=28`.
