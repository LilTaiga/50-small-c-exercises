# 28 — Rejected prefix

Implement `size_t my_strcspn(const char *s, const char *rejected)`.

Given two strings `s` and `rejected`, count how many characters at the start
of `s` don't appear in `rejected`, stopping at the first one that does.
Return that count.

Examples:

- s `"hello,world"`, rejected `",;"` -> `5`
- s `"name=value"`, rejected `"="` -> `4`
- s `"123abc"`, rejected `"0123456789"` -> `0`
- s `"abc"`, rejected `"xyz"` -> `3`
- s `"abc"`, rejected `""` -> `3`
- s `""`, rejected `"abc"` -> `0`

> [!Tip]
> This is the opposite of [`my_strspn`](./27.md).

Run `make run N=28`; check with `make test N=28`.
