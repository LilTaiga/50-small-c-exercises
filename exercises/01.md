# 01 — Is it a digit?

Implement `int my_isdigit(int c)` in `01.c`.

Return nonzero for ASCII `'0'` through `'9'`, and zero otherwise. Accept any
`int`; values outside the ASCII range are not digits. This is deliberately not
locale-dependent. Do not use `<ctype.h>` functions. Earlier helpers are allowed.

Examples: `'7'` → true; `'a'` → false.

Run `make run N=1`; check with `make test N=1`.
