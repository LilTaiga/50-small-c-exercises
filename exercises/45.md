# 45 — Generic binary search

Implement the `my_bsearch` signature in `include/exercises.h`.

Search `count` records of `size` bytes sorted according to `compare`. Call it
as `compare(key, element)`; its sign describes key relative to element. Return
a pointer to any matching element, or `NULL`. Use binary search with logarithmic
comparisons, without modifying input. Size is positive and `count * size` fits
in `size_t`. Key and callback are valid; base provides the records and may be
`NULL` when count is zero. No library searching functions; earlier helpers are
allowed.

Example: integers `[1, 3, 5]`, key `3` → pointer to the middle integer.
Integers `[2, 4, 6, 8]`, key `6` → pointer to the third integer.

Run `make run N=45`; check with `make test N=45`.
