# 08 — Clamp an integer

Implement `int clamp_int(int value, int minimum, int maximum)`.

The caller guarantees `minimum <= maximum`. Return `minimum` if the value is
below it, `maximum` if above it, and the value otherwise. Do not use library
functions that perform the task. Earlier helpers are allowed.

Examples: `(15, 0, 10)` → `10`; `(4, 0, 10)` → `4`.

Run `make run N=8`; check with `make test N=8`.
