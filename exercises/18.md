# 18 — Copy and pad

Implement `char *my_strncpy(char *destination, const char *source, size_t count)`.

Write exactly `count` bytes: copy source bytes until its terminator, then fill
the rest with null bytes. If no terminator occurs within `count` source bytes,
do not append one. Return destination. Source is a valid string, destination has
at least `count` writable bytes, pointers are valid, and regions do not overlap.
Leave later bytes unchanged. No library string-copy functions; earlier helpers
are allowed.

Examples: source `"hi"`, count `5` → bytes `68 69 00 00 00`;
source `"hello"`, count `3` → bytes `68 65 6C`.

Boundary cases: a zero count leaves every destination byte unchanged.
An empty source with count `3` writes `00 00 00`. If count exactly equals
the source length, there is no room for its terminator: `"hi"`, count `2`
writes only `68 69`. With count `3`, it writes `68 69 00`.

This is **not** a general-purpose "safe strcpy"; its result is not always a
terminated string.

Run `make run N=18`; check with `make test N=18`.
