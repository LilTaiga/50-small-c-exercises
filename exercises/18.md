# 18 — Copy and pad

Implement `char *my_strncpy(char *destination, const char *source, size_t count)`.

Given a string `source`, a `destination` pointer, and a number `count`, write
exactly `count` characters into `destination`, copying characters from
`source`, and return a pointer to `destination`.

If source has at least `count` characters, copy exactly `count` characters
without adding a null terminator.
Otherwise, copy its characters and fill the remaining positions with null
bytes, writing exactly `count` bytes in total.

Examples:

- source `"hi"`, count `3` -> write `68 69 00`
- source `"hi"`, count `5` -> write `68 69 00 00 00`
- source `"hi"`, count `2` -> write `68 69`

Run `make run N=18`; check with `make test N=18`.
