# 39 — Join strings

Implement `char *string_join(const char *const *strings, size_t count, const char *separator)`.

Allocate one terminated string containing all `count` strings, with separator
between adjacent strings only. All provided strings and separator are valid;
the pointer array has `count` entries and may be `NULL` when count is zero.
Zero strings produce an allocated empty string. Return `NULL` for size overflow
or allocation failure. Preserve every input. Caller frees the result.

Use real `malloc`/`free` and earlier helpers; no library string functions.

Example: `["red", "green", "blue"]`, `", "` → `"red, green, blue"`.

Run `make run N=39`; check with `make test N=39`.
