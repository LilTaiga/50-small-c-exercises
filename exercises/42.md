# 42 — Decode little-endian bytes

Implement `uint32_t read_u32_le(const unsigned char bytes[4])`.

Read four bytes, least significant byte first, and return their 32-bit unsigned
value. Input is valid and stays unchanged. This exercise requires 8-bit bytes
and an available `uint32_t`. Do not assume host endianness or pointer alignment,
and do not cast input to an integer pointer. Use shifts and bitwise operations,
not library endian-conversion functions. Earlier helpers are allowed.

Example: `78 56 34 12` → `0x12345678`.

Run `make run N=42`; check with `make test N=42`.
