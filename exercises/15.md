# 15 — Last character match

Implement `char *my_strrchr(const char *s, int c)`.

Like the previous exercise, but return the last occurrence. Convert `c` to
`char`, include the terminating null byte in the search, and return `NULL` if
absent. Input is a valid string and must not change. No library search
functions; earlier helpers are allowed.

Example: `("banana", 'n')` → input buffer + 4.

Boundary cases: the first byte can also be the last match. Searching for
`'\0'` returns the terminator. An empty string contains only that terminator.

Run `make run N=15`; check with `make test N=15`.
