# 15 — Last character match

Implement `char *my_strrchr(const char *s, int c)`.

Given a string `s` and an integer `c`, find the last occurrence of character `c` in `s` and return a pointer to it.
Return `NULL` if the character was not found.

Examples:

- `("banana", 'n')` -> input buffer + 4
- `("banana", 'b')` -> input buffer
- `("banana", 'd')` -> NULL

> [!Warning]
> The null byte is considered part of the string.

Run `make run N=15`; check with `make test N=15`.
