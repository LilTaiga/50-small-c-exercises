# 24 — Compare memory

Implement `int my_memcmp(const void *a, const void *b, size_t count)`.

Given two pointers `a` and `b`, and a number `count`, compare the first `count`
bytes of `a` and `b` with a bytewise **lexicographic ordering**.

Return:

- **A negative integer** if `a` comes before `b`.
- **Zero** if `a` and `b` are equal.
- **A positive integer** if `a` comes after `b`.

Examples:

- a `"cat"`, b `"dog"`, count `3` -> `negative`
- a `"cat"`, b `"car"`, count `3` -> `positive`
- a `"cat"`, b `"car"`, count `2` -> `zero`
- a `"cat"`, b `"dog"`, count `0` -> `zero`
- a `01 02`, b `01 03`, count `2` -> `negative`
- a `41 00 20`, b `41 00 30`, count `3` -> `negative`
- a `41 00 FF`, b `41 00 7F`, count `3` -> `positive`

> [!Tip]
> Unlike [`my_strcmp`](./13.md), `my_memcmp` doesn't stop at a null byte; it
> always compares exactly `count` bytes.

> [!Important]
> This exercise involves byte comparison. Refer to the caution in [exercise
> 11](./11.md) about comparing bytes.
