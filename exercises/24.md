# 24 — Compare memory

Implement `int my_memcmp(const void *a, const void *b, size_t count)`.

Compare exactly `count` unsigned bytes, returning a negative/zero/positive value
according to the first difference. Both pointers are valid and have enough
readable bytes; inputs remain unchanged. Nonzero magnitude is unspecified.
No library comparison functions; earlier helpers are allowed.

Example: `41 00 FF` sorts after `41 00 7F`.

There are additional edge cases to consider.

Run `make run N=24`; check with `make test N=24`.
