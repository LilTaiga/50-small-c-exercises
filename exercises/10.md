# 10 — Sum an array

Implement `int array_sum(const int *values, size_t count)`.

Sum exactly `count` elements. The caller supplies enough readable elements,
and every left-to-right partial sum fits in `int`. Do not modify the array.
Do not use library aggregation helpers. Earlier helpers are allowed.

Examples: `[3, -1, 5]` → `7`; `[2, 4]` → `6`.

Boundary cases: zero elements sum to zero, and the pointer may then be `NULL`.
A one-element array returns its element; negative totals are valid.

Run `make run N=10`; check with `make test N=10`.
