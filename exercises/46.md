# 46 — Growable integer vector

Implement `int vector_push(IntVector *vector, int value)`.

`IntVector` contains `data`, `length`, and `capacity` (in elements). Its address
is valid; initially use `{0}`. Existing vectors own malloc-compatible storage
for capacity elements, with `length <= capacity` and a representable allocation
size. Append value and return `0`, growing storage when needed. Preserve the
existing elements. Choose any growth policy; maintain valid metadata. Return
`-1` on size/allocation failure, leaving all fields and existing values unchanged.
Use spare capacity without reallocating. Caller eventually frees `data`.

Use real `malloc`/`realloc`/`free` and earlier helpers, not external containers.

Example: push `42` into `{0}` → length `1`, first element `42`.

Run `make run N=46`; check with `make test N=46`.
