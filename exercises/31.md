# 31 — Decimal prefix conversion

Implement `int my_atoi(const char *s)`.

Skip ASCII whitespace, accept one optional `+` or `-`, then consume decimal
digits until the first other byte. Return the signed value, or zero if no
digits were consumed. Input is a valid string; every consumed numeric value
is representable as `int`. Preserve input.

No library number parsers (`atoi`, `strtol`, `sscanf`, etc.) or `<ctype.h>`
functions. Earlier helpers are allowed.

Examples: `"  -42 cats"` → `-42`; `"123abc"` → `123`.

Run `make run N=31`; check with `make test N=31`.
