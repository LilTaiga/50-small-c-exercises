# 04 — Whitespace

Implement `int my_isspace(int c)`.

Return nonzero for space, horizontal tab, newline, carriage return, vertical
tab, and form feed; zero otherwise. Accept any `int`. Do not use `<ctype.h>`.
Earlier helpers are allowed.

Examples: `' '` → true; `'x'` → false.

Run `make run N=4`; check with `make test N=4`.
