# 44 — Insertion sort

Implement `void array_sort(int *values, size_t count)`.

Sort exactly `count` writable integers in ascending order using insertion sort,
in place with constant extra space. The pointer may be `NULL` when count is
zero. Support every `int` value without subtraction-based comparison overflow.
No library sorting functions or allocation. Earlier helpers are allowed.

Examples: `[3, 1, 2]` → `[1, 2, 3]`; `[8, -2, 4, 1]` → `[-2, 1, 4, 8]`.

Run `make run N=44`; check with `make test N=44`.
