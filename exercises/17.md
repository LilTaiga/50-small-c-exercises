# 17 — Bounded comparison

Implement `int my_strncmp(const char *a, const char *b, size_t count)`.

Compare at most `count` bytes, stopping at a differing byte or a string
terminator. Return only the appropriate negative/zero/positive sign. Compare
as unsigned bytes. Inputs are valid strings and remain unchanged. No library
comparison functions; earlier helpers are allowed.

Example: `("hello", "help", 3)` → zero.

There are additional edge cases to consider.

Run `make run N=17`; check with `make test N=17`.
