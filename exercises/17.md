# 17 — Bounded comparison

Implement `int my_strncmp(const char *a, const char *b, size_t count)`.

Given two strings `a` and `b`, and a number `count`, compare up to `count`
characters in **lexicographic ordering** and return an `int` indicating which
string comes first.

Examples:

- `("abcd", "abce", 4)` -> `negative`
- `("abcd", "abce", 3)` -> `zero`
- `("abcd", "abc", 4)` -> `positive`

> [!Note]
> Refer to [exercise 13](./13.md) about lexicographical order

Run `make run N=17`; check with `make test N=17`.
