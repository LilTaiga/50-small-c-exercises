# 16 — Append a string

Implement `char *my_strcat(char *destination, const char *source)`.

Append the source string at the destination's terminator, including a new
terminator. Return the original destination pointer. Inputs are valid strings,
the destination has sufficient writable capacity, and the regions do not
overlap. Preserve bytes after the resulting terminator and do not change source.
No library concatenation functions; earlier helpers are allowed.

Examples: `"hello"` + `" C"` → `"hello C"`; `"low"` + `"level"` → `"lowlevel"`.

Boundary cases: appending to an empty destination copies the source:
`""` + `"cat"` → `"cat"`. An empty source leaves the destination string
unchanged: `"cat"` + `""` → `"cat"`. Two empty strings produce `""`, with
one terminating null byte still stored in the destination.

Run `make run N=16`; check with `make test N=16`.
