# 16 — Append a string

Implement `char *my_strcat(char *destination, const char *source)`.

Given two strings `source` and `destination`, append the characters of `source`
at the end of `destination` and return the `destination`.
Assume that `destination` has sufficient capacity for the characters of
`source` and the null byte.

Examples:

- `"hello"` + `" C"` -> `"hello C"`
- `"low"` + `"level"` -> `"lowlevel"`
- `""` + `"cat"` -> `"cat"`
- `"cat"` + `""` -> `"cat"`
- `""` + `""` -> `""`

Run `make run N=16`; check with `make test N=16`.
