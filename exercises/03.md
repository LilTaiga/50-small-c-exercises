# 03 — Letters or digits

Implement `int my_isalnum(int c)` using your earlier classification helpers.
Move their implementations into `lib.c` as described in the README.

Return nonzero for ASCII letters or decimal digits, zero otherwise; accept any
`int`. Do not use `<ctype.h>` functions.

Examples: `'b'` → true; `'8'` → true; `'!'` → false.

Boundary cases: `'0'`, `'9'`, `'A'`, `'Z'`, `'a'`, `'z'` qualify. `'_'`, a space,
`-1`, and `256` do not.

Run `make run N=3`; check with `make test N=3`.
