# 33 — Integer to decimal string

Implement `int int_to_string(int value, char *destination, size_t capacity)`.

Write the complete decimal representation, with a minus sign only for negative
values and no unnecessary leading zeros, then a null byte. Support every `int`.
Return `0` on success. Return `-1` if capacity cannot hold the entire result
including the terminator, leaving destination unchanged. On success preserve
bytes beyond the terminator. Destination provides `capacity` writable bytes;
it may be `NULL` only when capacity is zero. Do not allocate.

No library formatting or number-conversion functions. Earlier helpers are allowed.

Examples: `42` → `"42"`; `-17` → `"-17"` with sufficient capacity.

Run `make run N=33`; check with `make test N=33`.
