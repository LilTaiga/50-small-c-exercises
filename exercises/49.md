# 49 — Remove matching list nodes

Implement `size_t list_remove_if(IntNode **head, int (*predicate)(int))`.

The head address and callback are valid; the list is finite, acyclic, and owns
individually malloc-allocated nodes. Call predicate once for each original node.
Remove and free nodes for which it returns nonzero. Preserve the addresses and
relative order of surviving nodes. Update `*head` and return the removal count.
The callback does not modify the list. Do not allocate new nodes.

Use real `free` and earlier helpers; no external containers.

Example: `[1, -2, 3, -4]`, predicate `value < 0` → `[1, 3]`, removed `2`.
`[2, 5, 8, 9]`, predicate `value % 2 == 0` → `[5, 9]`, removed `2`.

Run `make run N=49`; check with `make test N=49`.
