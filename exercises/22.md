# 22 — Copy memory

Implement `void *my_memcpy(void *destination, const void *source, size_t count)`.

Copy exactly `count` bytes and return destination. Both pointers are valid;
the source has enough readable bytes and destination enough writable bytes.
The regions do not overlap. Preserve source and bytes outside the destination
region. Do not interpret bytes as a string. No library memory-copy functions;
earlier helpers are allowed.

Example: copying bytes `41 00 FF` copies all three bytes.

There are additional edge cases to consider.

Run `make run N=22`; check with `make test N=22`.
