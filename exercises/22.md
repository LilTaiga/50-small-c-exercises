# 22 — Copy memory

Implement `void *my_memcpy(void *destination, const void *source, size_t count)`.

Given a `destination` pointer, a `source` pointer, and a number `count`, copy
the first `count` bytes of `source` into `destination` and return a pointer to
`destination`.
Assume that `source` and `destination` don't overlap.

Examples:

- destination `"XXXXX"`, source `"hello"`, count `3` -> `"helXX"`
- destination `"dog"`, source `"cat"`, count `0` -> `"dog"`
- destination `00 00 00 00`, source `41 00 FF`, count `3` -> `41 00 FF 00`
- destination `55 55 55`, source `00 00 00`, count `2` -> `00 00 55`
- destination `AA BB CC DD`, source `7F 80 FF 01`, count `4` -> `7F 80 FF 01`
- destination `AA BB`, source `11 22`, count `0` -> `AA BB`

Run `make run N=22`; check with `make test N=22`.
