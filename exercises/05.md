# 05 — Uppercase

Implement `int my_toupper(int c)`.

Convert ASCII `a`–`z` into `A`–`Z`. Return every other input unchanged, including
values outside ASCII. Do not use `<ctype.h>`. Earlier helpers are allowed.

Examples: `'g'` → `'G'`; `'4'` → `'4'`.

Run `make run N=5`; check with `make test N=5`.
