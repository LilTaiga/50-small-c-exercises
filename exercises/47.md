# 47 — Growable byte buffer

Implement `int buffer_append(ByteBuffer *buffer, const void *data, size_t count)`.

`ByteBuffer` owns malloc-compatible storage with length and capacity measured
in bytes; start with `{0}`. Append exactly `count` bytes and return `0`, growing
as needed. Preserve previous contents. No terminator is implied. Source must
not overlap buffer storage. Use spare capacity without reallocating.

Buffer is valid with `length <= capacity`. Validate length addition before
reading source. For a representable new length, source supplies count readable
bytes; it may be `NULL` when count is zero. A zero-byte append succeeds without
changing any fields. On size/allocation failure return `-1`, preserving all
fields and contents. Caller eventually frees `data`.

Use real `malloc`/`realloc`/`free` and earlier helpers; no library memory copying
or external containers.

Example: append `41 00 FF` to `42` → `42 41 00 FF`.

Run `make run N=47`; check with `make test N=47`.
