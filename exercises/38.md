# 38 — Allocate a slice

Implement `char *string_slice(const char *s, size_t start, size_t length)`.

Input is a valid string. Require `start <= string length` and `length <= string
length - start`. Return `NULL` if the requested range is invalid or allocation
fails. Otherwise allocate exactly the selected bytes plus a null terminator.
Preserve input. Caller owns and frees the result. Use real `malloc`/`free` and
earlier helpers, not library string or memory-copy functions.

Examples: `("hello world", 6, 5)` → `"world"`; `("abcdef", 1, 3)` → `"bcd"`.

Run `make run N=38`; check with `make test N=38`.
