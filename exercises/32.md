# 32 — Checked integer parsing

Implement `ParseResult parse_int(const char *s, int *result)`.

Accept a whole string matching `[+-]?[0-9]+`, without whitespace. Return
`PARSE_OK` and write the integer on success; `PARSE_INVALID` for invalid syntax;
or `PARSE_OVERFLOW` for syntactically valid numbers outside `INT_MIN`–`INT_MAX`.
On failure leave `*result` unchanged. Both pointers are valid; preserve input.
Use `<limits.h>` for integer bounds, not assumed 32-bit constants.

No library number parsers or formatting functions. Earlier helpers are allowed.
Avoid signed arithmetic overflow while parsing.

Examples: `"-42"` → `PARSE_OK`, result `-42`; `"12cats"` → `PARSE_INVALID`.

Run `make run N=32`; check with `make test N=32`.
