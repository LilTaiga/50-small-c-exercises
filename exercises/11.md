# 11 — String length

Implement `size_t my_strlen(const char *s)`.

Return the number of bytes before the first null byte. Input is a valid
null-terminated string; do not modify it. Do not call `strlen`, `strnlen`, or
another library function to measure the string. Earlier helpers are allowed.

Examples: `"hello"` → `5`; `"C!"` → `2`.

Boundary cases: `""` has length zero; `{'a', '\0', 'b', '\0'}` has length one.
A newline counts as one byte. `NULL` is not a valid string.

Run `make run N=11`; check with `make test N=11`.
