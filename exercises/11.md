# 11 — String length

Implement `size_t my_strlen(const char *s)`.

Return the number of characters the string `s` has, excluding the null byte.

Examples:

- `"hello"` -> `5`
- `"C!"` -> `2`

> [!Important]
> A character in this context means any `char`.
> All byte values from `0x00` to `0xFF` are considered characters, even though
> ASCII only covers `0x00`–`0x7F`.
>
> Keep this in mind for the next exercises.

> [!Caution]
> When comparing characters, be wary of the signedness of your `char` type.
> Byte `0xFF` should be considered **above** byte `0x7F`, not below.

Run `make run N=11`; check with `make test N=11`.
