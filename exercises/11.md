# 11 — String length

Implement `size_t my_strlen(const char *s)`.

Return the number of characters the string `s` has, excluding the null byte.

> [!Important]
> A character in this context means any `char`.
> Byte `0x87` is considered a character, even though it doesn't have a mapping
> in the ASCII table.
>
> Keep this in mind for the next exercises.

Examples: `"hello"` → `5`; `"C!"` → `2`.

Run `make run N=11`; check with `make test N=11`.
