# 27 — Accepted prefix

Implement `size_t my_strspn(const char *s, const char *accepted)`.

Return the length of the initial segment of `s` containing only characters
listed in `accepted`. Both inputs are valid strings and remain unchanged.
The terminating null byte is not a set member. No library span functions;
earlier helpers are allowed.

Example: `("123abc", "0123456789")` → `3`.

There are additional edge cases to consider.

Run `make run N=27`; check with `make test N=27`.
