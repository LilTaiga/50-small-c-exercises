# 27 — Accepted prefix

Implement `size_t my_strspn(const char *s, const char *accepted)`.

Given two strings `s` and `accepted`, count how many characters at the start
of `s` appear in `accepted`, stopping at the first one that doesn't.
Return that count.

Examples:

- s `"123abc"`, accepted `"0123456789"` -> `3`
- s `"aaab!"`, accepted `"ab"` -> `4`
- s `"hello,world"`, accepted `",;"` -> `0`
- s `"abc"`, accepted `"abc"` -> `3`
- s `"baba"`, accepted `"aab"` -> `4`
- s `"abc"`, accepted `""` -> `0`
- s `""`, accepted `"abc"` -> `0`

Run `make run N=27`; check with `make test N=27`.
