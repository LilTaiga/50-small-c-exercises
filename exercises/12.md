# 12 — Copy a string

Implement `char *my_strcpy(char *destination, const char *source)`.

Copy the source including its terminating null byte; return the original
destination pointer. The destination has enough space, both pointers are valid,
and the regions do not overlap. Leave bytes after the copied terminator alone.
No library string-copy functions; earlier helpers are allowed.

Example: copying `"cat"` writes `{'c','a','t','\0'}`.

Boundary cases: copying `""` still writes one null byte. A destination of
exactly `length + 1` bytes is sufficient. Do not alter the source.

Run `make run N=12`; check with `make test N=12`.
