# 12 — Copy a string

Implement `char *my_strcpy(char *destination, const char *source)`.

Copy the characters from `source` onto `destination`, including the null byte,
and return a pointer to the `destination`.
Assume `destination` has enough space for the characters from `source` and the
null byte. Both pointers are valid. If `destination` has more bytes than
necessary, the remaining bytes should be left untouched.

Example: copying `"cat"` writes `{'c','a','t','\0'}`.

Run `make run N=12`; check with `make test N=12`.
