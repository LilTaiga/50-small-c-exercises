# 48 — Append a linked-list node

Implement `int list_push_back(IntNode **head, int value)` and
`void list_free(IntNode *head)`.

`IntNode` contains an integer value and a next pointer. `head` is valid and
points to a finite acyclic chain of individually malloc-allocated nodes or
`NULL`. Append a newly allocated node, preserving existing node addresses and
order. Set its next pointer to `NULL`. Return `0` on success, `-1` on allocation
failure without altering the list. The cleanup helper frees every node and
accepts a null head. Ownership of appended nodes belongs to the list.

Use real `malloc`/`free` and earlier helpers; no external containers.

Example: `[3, 1]`, append `4` → `[3, 1, 4]`.
Appending `-2` next gives `[3, 1, 4, -2]`.

Run `make run N=48`; check with `make test N=48`.
