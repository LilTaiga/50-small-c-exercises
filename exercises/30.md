# 30 — Stateful tokenization

Implement `char *next_token(char *s, const char *delimiters, char **state)`.

Given a string `s` and a set of `delimiters`, split `s` into **tokens**: the
pieces of text between delimiters.
Each call to `next_token` returns one token, so you call it again and again
until it returns `NULL`.

For example, splitting `"red,green,blue"` on `","` gives `"red"`, then
`"green"`, then `"blue"`, then `NULL`:

```c
char s[] = "red,green,blue";
char *state;

next_token(s, ",", &state);    // "red"    s is now "red\0green,blue"
next_token(NULL, ",", &state); // "green"  s is now "red\0green\0blue"
next_token(NULL, ",", &state); // "blue"
next_token(NULL, ",", &state); // NULL
```

Calling it:

- Pass the string as `s` on the first call, and `NULL` on the calls after that
  to keep going through the same string.
- `state` points to a variable that belongs to the caller. Use `*state` to
  remember where the next call should continue. On the first call, ignore
  what's in it.
- `delimiters` may be different on each call.

What each call does:

- Skip any delimiters before the token. Delimiters at the start, at the end, or
  next to each other never produce empty tokens.
- Replace the delimiter right after the token with a null byte, so the token
  becomes a string of its own.
- Return a pointer to the token's first character. It points into `s`, so
  don't copy or allocate anything.
- When there are no tokens left, set `*state` to `NULL` and return `NULL`.
  Calls after that also return `NULL`.

Examples:

- s `",red;;green,blue,"`, delimiters `",;"` -> `"red"`, `"green"`, `"blue"`, `NULL`
- s `"a:b,c"`, delimiters `":"`, then `","`, then `""` -> `"a"`, `"b"`, `"c"`
- s `""`, delimiters `","` -> `NULL`
- s `",,,"`, delimiters `","` -> `NULL`
- s `"whole"`, delimiters `""` -> `"whole"`

> [!Important]
> Don't use global or `static` variables. Everything the next call needs must
> be in `*state`, so two strings can be tokenized at the same time with
> separate `state` variables.

> [!Tip]
> [`my_strspn`](./27.md) and [`my_strcspn`](./28.md) can find where a token
> starts and where it ends.
