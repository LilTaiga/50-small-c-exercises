# 30 — Stateful tokenization

Implement `char *next_token(char *s, const char *delimiters, char **state)`.

For a new writable string, pass it as `s`; ignore the previous `*state`.
For subsequent calls pass `NULL` as `s`. Skip delimiter characters, return
the next nonempty token inside the original buffer, and replace its ending
delimiter (if any) with a null byte. Save continuation in `*state`. When the
string is exhausted set `*state = NULL`; further continuation calls return
`NULL`. The delimiter string may change on every call.

`state` and `delimiters` are valid pointers; delimiters is a valid string.
Independent state variables must allow interleaved scans. No hidden global or
static scan state. No library tokenizers; earlier helpers are allowed.

Example: `"red,green,blue"`, delimiter set `","` → `"red"`, `"green"`, `"blue"`.
Returned tokens are borrowed, not allocated. Do not free them.

There are additional edge cases to consider.

Run `make run N=30`; check with `make test N=30`.
