# 14 — First character match

Implement `char *my_strchr(const char *s, int c)`.

Search a valid string for the first occurrence of `c` converted to `char`.
Return its address inside the original string, or `NULL`. The terminating null
byte is part of the search. Do not modify the string. Do not use library search
functions; earlier helpers are allowed.

Example: `("banana", 'n')` → input buffer + 2.

Boundary cases: repeated characters return the first match; searching for
`'\0'` returns the terminator's address, including for an empty string.
A missing character returns `NULL`.

Run `make run N=14`; check with `make test N=14`.
