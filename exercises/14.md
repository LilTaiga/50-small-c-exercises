# 14 — First character match

Implement `char *my_strchr(const char *s, int c)`.

Given a string `s` and an integer `c`. Search the string for the first
occurrence of character `c` in the string and return a pointer to that
character. Return `NULL` if the character wasn't found.

Examples:

- `("banana", 'b')` -> input buffer
- `("banana", 'n')` -> input buffer + 2
- `("banana", 'd')` -> `NULL`

> [!Warning]
> The null byte is considered part of the string.

Run `make run N=14`; check with `make test N=14`.
