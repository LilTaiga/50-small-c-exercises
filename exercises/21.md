# 21 — Fill memory

Implement `void *my_memset(void *destination, int value, size_t count)`.

Write `count` bytes, each equal to `value` converted to `unsigned char`; return
destination. The pointer is valid and has at least `count` writable bytes.
Leave all other bytes alone. No library memory-fill functions; earlier helpers
are allowed.

Example: filling the first three bytes of `"hello"` with `'*'` gives `"***lo"`.

There are additional edge cases to consider.

Run `make run N=21`; check with `make test N=21`.
