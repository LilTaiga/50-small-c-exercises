# 21 — Fill memory

Implement `void *my_memset(void *destination, int value, size_t count)`.

Given a `destination` pointer, a `value`, and a number `count`, set the first
`count` bytes of `destination` to `value` and return a pointer to
`destination`.

Examples:

- destination `"hello"`, value `'*'`, count `3` -> `"***lo"`
- destination `"world"`, value `'?'`, count `2` -> `"??rld"`
- destination `"cat"`, value `'x'`, count `0` -> `"cat"`
- destination `00 00 00 00`, value `0x41`, count `2` -> `41 41 00 00`
- destination `00 00 00 00`, value `-1`, count `3` -> `FF FF FF 00`
- destination `00 00 00 00`, value `0x123`, count `4` -> `23 23 23 23`

> [!Important]
> `value` is an `int`, but a byte only holds values from `0x00` to `0xFF`.
> Only the lowest byte of `value` is written. So `0x123` writes `0x23`, and
> `-1` writes `0xFF`.

Run `make run N=21`; check with `make test N=21`.
