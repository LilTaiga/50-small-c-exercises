# 40 — Split with ownership

Implement `char **string_split(const char *s, char delimiter, size_t *count)`
and `void string_split_free(char **strings, size_t count)`.

Split at every occurrence of the non-null delimiter. Preserve empty fields.
Allocate the pointer array and every terminated field independently; input is
a valid string and remains unchanged. `count` is valid. On success write the
number of fields (delimiter occurrences plus one). No sentinel pointer is
required. On any size/allocation failure release partial allocations, set
`*count = 0`, and return `NULL`.

The cleanup helper releases all fields and the array; `(NULL, 0)` is valid.
Use real `malloc`/`realloc`/`free` and earlier helpers; no library tokenizers
or string functions.

Example: `"red,green,blue"`, `','` → `["red", "green", "blue"]`, count `3`.
`"usr/local/bin"`, `'/'` → `["usr", "local", "bin"]`, count `3`.

Run `make run N=40`; check with `make test N=40`.
